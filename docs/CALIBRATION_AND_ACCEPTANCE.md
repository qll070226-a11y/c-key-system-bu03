# 标定与验收

## 当前区域逻辑

门锁判断使用“钥匙到门锁圆柱边界的径向距离”，不是到某个Anchor的距离。

| 功能 | 进入阈值 | 退出阈值 |
|---|---:|---:|
| 开锁区 | 0.90m | 1.10m |
| 迎宾区 | 1.90m | 2.10m |
| 有效角度 | 绝对值43度 | 绝对值47度 |

不同进入/退出阈值构成滞回，避免边界抖动。只有ID一致、UWB有效、定位有效且角度合格时才允许迎宾或开锁。

## 当前滤波链路

```text
原始A0/A1距离
  -> 每路5点中值 + EMA(alpha=0.35)
  -> 双基站二维定位
  -> 方位角5点中值
  -> 自适应角度EMA（静止alpha=0.15，移动alpha=0.60，阈值3度）
  -> 角度滞回与区域状态机
```

静止时使用较小系数降低显示和判定抖动；角度中值相对当前输出变化达到3度时使用较大系数提高动态跟随速度。UWB丢失或定位无效会清空角度滤波状态，恢复后的首个有效角度直接生效。该滤波不修正固定偏差、多径或左右不对称问题。

## 最终标定步骤

1. 固定外壳、Anchor、TFT、电池、DCDC和所有线束。
2. 实测两个Anchor天线中心相对门锁中心的X/Y坐标。
3. 在1、1.5、2、3m附近分别静止采集至少20帧，使用中位数。
4. 将数据填入`tools/calibration_measurements.csv`。
5. 运行：

```powershell
.\tools\calibrate_ranges.ps1 .\tools\calibration_measurements.csv
```

6. 更新`sdkconfig.defaults`中的scale和offset，并重新构建烧录。
7. 在0、正负30、正负45度独立验证，不得使用同一批点同时拟合和验收。

角度验证时除了记录平均误差，还应记录标准差和MAD。滤波后的曲线变稳不代表绝对角度准确；若平均误差超标，应优先检查距离标定、天线高度、遮挡和多径，而不是继续降低静止EMA系数。

## 必做验收清单

- [ ] 1、2、3m静态径向距离误差满足题目要求。
- [ ] 0、正负30、正负45度方位角误差绝对值不超过10度。
- [ ] 从3m外向内移动：感应、迎宾、开锁顺序正确。
- [ ] 从开锁区向外移动：闭锁和迎宾关闭顺序正确，无反复抖动。
- [ ] 四位拨码修改认可ID后，原Tag立即失效并闭锁。
- [ ] 断开Tag或Anchor后500ms内显示`NO KEY`并闭锁。
- [ ] 定位无解、残差过大或异常帧时保持闭锁。
- [ ] 断电重启后默认闭锁，不产生误开锁脉冲。
- [ ] 连续运行30分钟，无复位、花屏、持续丢帧或异常发热。
- [ ] 电池供电和USB调试供电分别测试，确认无反向灌电。

每次验收应保存测试日期、机械布局照片、卷尺读数、Tag姿态、原始串口日志和结果CSV。
