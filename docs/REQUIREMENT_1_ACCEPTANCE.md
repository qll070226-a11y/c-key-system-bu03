# C题第1项验收步骤

题目要求：数字钥匙一键启动后持续发送身份ID；门锁在感应区检测、接收并显示ID；
通信距离不小于3m。

## 当前实现

- BU03-Kit电源开关是一键启动开关。
- BU03通过UWB持续发送短地址0x6E19。
- BU04在每个PDOA帧中输出标签短地址、距离和角度。
- ESP32只把0x6E19映射为逻辑钥匙ID 0000，其他地址认证失败。
- TFT显示钥匙ID、门锁拨码ID和“匹配成功/匹配失败”。
- 500ms没有合法无线帧时进入NO_KEY并强制闭锁。

## 3米正式测试

1. BU04天线中心和BU03标签天线中心用卷尺布置到至少3.00m。
2. 两者保持视距、天线朝向固定，标签开关先关闭。
3. 上位机断开COM21，避免占用验收串口。
4. 运行：

~~~powershell
host\.venv\Scripts\python.exe tools\verify_requirement_1.py COM21 \
  --physical-distance-m 3.0 --display-confirmed
~~~

5. 看到提示后，在12秒内拨动标签电源开关。
6. 保持标签不动15秒，人工确认TFT显示：

~~~text
钥匙ID 0000
门锁ID 0000
身份认证 匹配成功
~~~

工具检查首次识别、持续时间、帧率、最大中断、地址/ID一致性、遥测错误和距离
合理性，并在reports目录生成JSON和Markdown报告。

若人工确认前先试跑，去掉--display-confirmed；此时报告会因缺少显示确认而标记
为未通过，这是预期行为。
