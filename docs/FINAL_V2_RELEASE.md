## 核心参数

- BU04 UART2_TX -> ESP32-S3 GPIO18，115200 baud，共地。
- 标签地址 0x6E19，逻辑 ID 0000。
- 距离：5点中值 + EMA，alpha=0.35。
- 角度：7点环形 Hampel + One Euro。
- One Euro：min_cutoff=0.8Hz，beta=0.03，d_cutoff=1.0Hz。
- Hampel：max(12度, 3倍稳健标准差)，最多连续拒绝3帧。
- 负角度分段校准：
  - 原始 -12.3度 -> 物理 -15度；
  - 原始 -28.2度 -> 物理 -30度；
  - 原始 -41.5度 -> 物理 -45度。
- 0度和正角度保持恒等映射。
- 开锁区和迎宾区使用正负5cm滞回，状态变化连续4帧确认。
- 掉线、坏帧、未知标签和ID不匹配立即闭锁。

## 实测结果

- 正前方约1m：距离约1.01m，角度约+1.85度，稳定开锁。
- 标签断电：TFT显示无钥匙，门锁关闭，开锁灯熄灭。
- 3m持续ID通信：15.010秒718帧，平均47.83Hz，解析错误0。
- 右侧定点30秒：原始角度标准差0.593度，旧滤波0.470度，
  本版滤波0.414度。
- 物理-45度复测：原始均值约-42.83度，校准显示均值约-46.35度。
- C核心测试全部通过；Python上位机14项测试全部通过。
- ESP-IDF 5.5.4完整构建通过。
- Bootloader、分区表和应用镜像烧录COM21时均通过SHA校验。

BU04当前输出的 first_path_power 和 rx_level 均为0，因此本版只记录这两个
字段，不启用信号质量门限。

以上实测不能替代完整赛场验收。当前证据状态见

## 使用

烧录前关闭上位机和其他占用 ESP32 串口的软件：

~~~powershell
.\flash_idf.bat COM21
~~~

启动上位机：

~~~powershell
cd host
.\run.bat
~~~

上位机连接 ESP32-S3 的 CH343 串口，不连接 BU04 原生数据口。

详细接线和交接内容见仓库根目录的 [HANDOFF.md](../HANDOFF.md)。
