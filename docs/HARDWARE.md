# 硬件与接线

## 系统拓扑

~~~text
数字钥匙：BU03-Kit Tag（0x6E19）
                  |
                 UWB
                  |
门锁：BU04-Kit PDOA Base -> UART2_TX -> ESP32-S3 GPIO18
                               |
                               +-> TFT / 拨码 / LED / 蜂鸣器
~~~

BU04 检测模块、ESP32、显示、供电和所有门锁元件都应位于题目规定的门锁圆柱
范围内。数字钥匙只保留 BU03 标签、电池、稳压和开关。

## BU04 与 ESP32

BU04-Kit 排针定义中：

| BU04引脚 | 功能 | 连接 |
|---:|---|---|
| 4 | UART2_TX，PDOA测距数据输出 | ESP32 GPIO18 |
| 5 | UART2_RX | 当前不接 |
| 22 | 5V | 独立5V DCDC |
| 1/10/21/37 | GND | 与ESP32公共地 |

BU04 UART2 为 115200、8N1。ESP32 只接收，不向 BU04 发送数据。

BU04 的两个 USB 接口用途不同：

- AT/烧写口：当前 COM14，只用于配置。
- 主测距数据口：当前 COM25，输出与 UART2 相同类型的二进制数据，供 PC 抓包。

正式运行不要求 COM25 连电脑；必须把 UART2_TX 引脚接到 GPIO18。调试时
COM25 可以保留用于旁路抓包，但不能与 ESP32 输入形成电气冲突。

## ESP32 GPIO

| 功能 | GPIO | 说明 |
|---|---:|---|
| BU04 UART RX | 18 | 接BU04 UART2_TX |
| 拨码bit0..3 | 4/5/6/7 | 每位10k上拉，开关闭合接地 |
| 蜂鸣器 | 8 | 低电平触发 |
| TFT D/C | 9 | 3.3V逻辑 |
| TFT CS | 10 | 3.3V逻辑 |
| TFT SDI/MOSI | 11 | 3.3V逻辑 |
| TFT CLK | 12 | 3.3V逻辑 |
| TFT SDO/MISO | 13 | 3.3V逻辑 |
| TFT BLK | 14 | 高电平开背光 |
| 闭锁红灯 | 15 | 串330欧姆 |
| 开锁绿灯 | 16 | 串330欧姆 |
| 迎宾灯 | 17 | 串330欧姆 |

ESP32 板底部左侧丝印 COM 的 Type-C 口用于烧录和上位机；右侧 USB 口当前不用。

## TFT

LVSN-TFT-2.4 实物只能接 3.3V：

~~~text
VCC  -> 3.3V
GND  -> GND
SDI  -> GPIO11
CLK  -> GPIO12
CS   -> GPIO10
SDO  -> GPIO13
D/C  -> GPIO9
BLK  -> GPIO14
~~~

曾在 VCC 约1.7V时完全不亮，改为3.3V后已正常显示。禁止接5V。

## 拨码、LED和蜂鸣器

拨码每位：

~~~text
3.3V -- 10k --+-- GPIO
               +-- 开关 -- GND
~~~

开关 ON 读作1，GPIO4为最低位。LED 为 GPIO -> 330欧姆 -> LED -> GND。

蜂鸣器模块为低电平触发，GPIO8低电平响。软件在进入迎宾区时输出500ms脉冲，
安全态保持高电平。裸蜂鸣器不得直接由 GPIO 供电。

## 正式供电

~~~text
12V电池
  +-- DCDC 1: 5V -> ESP32/扩展板
  |          3.3V -> TFT
  +-- DCDC 2: 5V -> BU04

所有GND在低阻公共点汇接
~~~

数字钥匙：

~~~text
带保护锂电池 -> 开关 -> 5V升压DCDC -> BU03-Kit
~~~

空载调整后再接模块：5V建议4.9到5.1V，3.3V建议3.25到3.35V。两路 DCDC
的5V输出不得并联，只允许共地。禁止使用漆包线缠绕供电。

## 射频布局

- BU04 双天线面朝测试扇区，正前方机械方向固定并做好0度标记。
- BU03 标签姿态固定，天线不要被手掌、身体、电池或金属遮挡。
- BU04 天线附近不要放电池、DCDC、TFT排线和大电流回路。
- 天线尽量离地并保持与标签天线相近高度，减少地面多径。
- 最终距离和角度参考点均以天线相位中心为准，不以外壳边缘为准。
