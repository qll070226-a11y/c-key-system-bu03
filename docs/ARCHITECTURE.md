# 系统架构与设计取舍

## 1. 目标与边界

系统需要在数字钥匙进入门锁感应范围后，同时完成身份识别、距离与方位测量、区域
判定和声光/门锁输出。题目既包含静态精度测试，也包含钥匙移动时的动态进入与离开
判决，因此方案不能只追求静态曲线平滑，还必须控制响应延迟和边界抖动。

本项目采用单个 BU04 PDOA 基站完成测距和测角。与早期“双 BU03 TWR 三边定位”
方案相比，它减少了基站间几何误差、同步与安装约束，且距离、角度和标签地址来自
同一数据帧，便于一致性校验。

## 2. 分层结构

| 层次 | 目录/模块 | 职责 |
|---|---|---|
| UWB 设备层 | BU03-Kit、BU04-Kit | 标签身份发送、TWR 测距、PDOA 测角 |
| 协议层 | `bu04_pdoa.c` | 31 字节帧解析、校验、标签地址和测量值提取 |
| 数据管线 | `c_key_pipeline.c` | 校准、离群抑制、平滑和有效性管理 |
| 业务核心 | `c_key_core.c` | 身份认证、二维换算、区域与门锁状态机 |
| 显示适配 | `c_key_display.c` | 将内部状态转换为稳定的界面字段 |
| 硬件输出 | `c_key_io`、`c_key_tft` | 拨码、LED、蜂鸣器、中文 TFT |
| 诊断链路 | `c_key_telemetry.c` | 输出结构化 `C_KEY_DIAG_V3` 遥测 |
| PC 工具 | `host/c_key_debugger` | 串口监控、曲线、轨迹、记录、回放和统计 |

核心算法保持为普通 C 模块，不直接依赖 FreeRTOS 或具体 GPIO。这样同一套代码既能在
ESP32-S3 上运行，也能由桌面 GCC 编译并执行单元测试。

## 3. 数据路径

1. BU03 标签持续发送 UWB 数据，BU04 生成包含标签地址、距离、PDOA 角度和信号质量
   的二进制帧。
2. ESP32 UART 接收任务把任意长度字节块交给流式解析器。
3. 解析器搜索帧头并验证长度和校验和；坏帧只增加错误计数，不更新业务状态。
4. 数据管线校正距离和角度，对离群点与高频噪声分别处理。
5. 核心状态机校验标签身份、计算边界距离与位置，并根据回差阈值决定区域和锁状态。
6. TFT、LED、蜂鸣器读取同一份状态快照，诊断串口同时输出原始值与各处理阶段结果。

## 4. 滤波与动态响应

### 距离

距离先通过 5 点中值滤波，压制多径或偶发坏测量造成的尖峰，再通过 EMA 平滑：

```text
y[k] = 0.35 * x[k] + 0.65 * y[k-1]
```

该组合计算量小、状态量固定，适合高频嵌入式更新。

### 角度

角度使用 7 点环形 Hampel 检测局部离群点，再使用 One Euro 滤波器。One Euro 根据
变化速度动态调整截止频率：静止时加强平滑，移动时减小滞后。当前参数为：

```text
min_cutoff = 0.8 Hz
beta = 0.03
derivative_cutoff = 1.0 Hz
```

由于实机在负角区域存在方向相关的系统偏差，完赛 2 版增加分段校准。校准仅修正
稳定的系统误差，不替代异常值检测。

## 5. 区域状态机

系统把 BU04 天线中心距离转换为门锁圆柱边界距离：

```text
boundary_distance = uwb_center_distance - 0.30 m
```

开锁区采用 0.95 m 进入、1.05 m 离开；迎宾区采用 1.95 m 进入、2.05 m 离开。
角度门限采用 43° 进入、47° 离开。进入条件比离开条件更严格，形成回差；候选状态
还需连续 4 帧成立才会提交，从而避免标签停在边界时 LED、蜂鸣器和锁频繁切换。

## 6. 失效保护

安全规则优先级高于普通区域转换：

- 上电默认闭锁；
- 超过 500 ms 没有有效 UWB 数据，立即进入无钥匙闭锁状态；
- 标签地址未知、逻辑 ID 与拨码 ID 不一致或定位无效时，不允许开锁；
- 前 5 个有效样本用于滤波预热，避免初始化瞬态误触发；
- 坏帧不会刷新数据存活时间，也不会沿用为新的有效位置。

这套设计保证“没有可靠证据时保持闭锁”，符合数字钥匙原型的基本故障安全原则。

## 7. 可观测性与可测试性

`C_KEY_DIAG_V3` 同时输出原始、校正、滤波、位置、状态和质量字段，使现场出现误判时
能够区分射频测量、解析、滤波、校准和业务阈值问题。Python 上位机提供实时可视化，
验收脚本则把同一遥测转换为可保存的 Markdown/JSON 证据。

自动测试覆盖：

- BU03/BU04 协议解析、坏帧拒绝与字节流重同步；
- 距离和角度滤波、校准和坐标换算；
- 身份匹配、区域回差、数据超时和断钥匙闭锁；
- 遥测格式、上位机解析、记录/回放与统计判定。

## 8. 已知边界

- UWB 在贴近地面、靠近金属或人体遮挡时仍会受到多径和非视距误差影响；
- 分段角度校准依赖当前天线安装姿态，改变外壳或天线方向后应重新标定；
- 当前 ID 机制用于竞赛身份判定，不提供密码学安全性；
- 正式宣称整机完赛前仍应完成全测点、双向动态边界、最终电源和长时间运行报告。

验证进度以[比赛验收状态](CONTEST_ACCEPTANCE_STATUS.md)为准。
