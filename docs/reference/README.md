# 参考资料

本目录保存团队实际使用的原始资料：

- `C题_基于无线通信的数字钥匙实验系统.docx`：比赛题目原文。
- `BU03_V1.1.0_规格书_20240724.pdf`：BU03模块厂家规格书。
- `BU03-Kit_V1.1.2规格书20260515B.pdf`：当前开发板规格、供电和引脚定义。
- `BU03_BU04_AT_command_cn_V1.0.6.pdf`：角色、ID、信道和设备参数查询指令。
- `BU03_BU04串口协议_V1.0.1.pdf`：UART2简化距离帧与主USB完整TWR身份帧定义。
- `BU03_UART2_测距数据帧协议_20240919.pdf`：37字节UART2测距帧专项说明。

当前固件同时使用UART2的37字节距离帧和主USB的101字节完整帧。厂家文档未明确完整帧XOR起点，项目已用实物确认范围为偏移6到97，回归样本见`tests/test_bu03_twr_usb.c`。

ULM3/PDOA是曾经调研的商家套件，不是当前实现方案，避免将其协议、引脚或性能参数套用到BU03-Kit。

题目答疑的关键约束已经体现在`HANDOFF.md`和硬件文档中。若题目原文、现场说明与本仓库描述冲突，以最新官方题目和现场裁判要求为准。
