# C题 UWB定位诊断上位机

该工具读取ESP32-S3 USB串口输出的 C_KEY_DIAG_V1，用于区分原始测距、线性校正、滤波和二维解算各阶段的误差。

## 安装

推荐Windows Python 3.13。首次运行：

    cd host
    .\setup.bat

依赖安装在 host/.venv，不会修改系统Python包。

## 启动

    .\run.bat

选择ESP32的CH343串口，默认波特率115200，点击“连接”。历史上ESP32曾使用COM21，但实际编号以设备管理器为准。

连接GUI前可先检查诊断帧：

    .\check_serial.bat COM21 --seconds 8

返回 diagnostics 大于0且 parse_errors 为0表示固件和上位机协议匹配。若日志显示 bytes=0、uart2_ok=0，应先检查Tag、两Anchor供电和Anchor 0到GPIO18的串口线。

没有硬件时可启动演示模式：

    .\run.bat --demo

演示数据故意加入左侧Anchor 1多径偏差，用来确认曲线和二维轨迹能显示不对称误差。

## 使用顺序

1. 先构建并烧录包含 C_KEY_DIAG_V1 的新固件。
2. 上位机连接ESP32的COM口，不连接Tag或BU03配置串口。
3. “实时诊断”观察A0/A1原始、校正和滤波曲线以及二维轨迹。
4. 打开“定点采集”，填写真实X、Y、离地高度和姿态说明。
5. 每个点采集至少300帧；0度、正负30度、正负45度分别采集。
6. 每种机械变化建立独立会话，例如“贴地”和“离地20cm”不能混在同一组。
7. 至少完成两个不同距离的测点后，点击“计算标定”查看比例和零偏建议。

标定结果不会自动写入固件，必须先检查MAE、最大误差和独立验证点，确认合理后再更新 sdkconfig.defaults。

## 页面说明

### 实时诊断

- 两个Anchor分别显示原始、校正和滤波距离。
- 角度曲线和定位残差以厘米同时显示。
- 二维图显示门锁圆柱、开锁边界、迎宾边界、Anchor、真实测点和定位轨迹。
- 帧质量显示协议接收成功数、坏帧数和上位机观察到的序号缺口。

### 定点采集

统计数量、均值、中位数、标准差、MAD、真实值和中位误差。MAD受偶发异常值影响较小，适合判断静态抖动；中位误差用于判断系统性偏差。

### CSV

“记录CSV”保存每一帧及当时填写的真实测点信息。保存的会话可以通过“回放”重新载入。host/output/默认不提交Git，避免把大量现场日志混入源码。
